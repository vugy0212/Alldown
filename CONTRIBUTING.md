# Contributing to AllDown

Thank you for your interest in contributing to **AllDown**!

## Reporting Issues
- Before opening a new issue, please check existing [GitHub Issues](https://github.com/vugy0212/Alldown/issues).
- Provide clear steps to reproduce, your Android OS version, and the target media service (e.g., YouTube, X/Twitter, TikTok, Facebook, Streamable, etc.).

## Pull Requests & Development Setup
1. Fork the repository and clone your fork:
   ```bash
   git clone https://github.com/vugy0212/Alldown.git
   cd Alldown/alldown
   ```
2. Install Flutter dependencies:
   ```bash
   flutter pub get
   ```
3. Verify static analysis and unit tests before submitting a PR:
   ```bash
   flutter analyze
   flutter test test/widget_test.dart
   ```
4. Ensure your code adheres to the [Code of Conduct](CODE_OF_CONDUCT.md) and maintains the GNU GPLv3 license.
